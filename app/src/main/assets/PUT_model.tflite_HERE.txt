Drop your trained detector here as exactly: model.tflite

The app runs without it (the overlay shows a note), but no boxes appear until
a model is present. Fastest route to one:

1. Capture a few hundred Fortnite frames on the device (screen-record, split to images).
2. Label enemy figures with Roboflow or CVAT (one class: "enemy").
3. Train YOLOv8n, then: yolo export model=best.pt format=tflite
4. Rename the exported file to model.tflite and place it in this assets folder.

Expected I/O (see Detector.kt): input 640x640 RGB float 0..1,
output [1][8400][6] = cx, cy, w, h, conf, class (normalized). Adjust Detector.kt if yours differs.
