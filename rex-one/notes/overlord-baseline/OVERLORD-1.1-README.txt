Overlord Baritone 1.1.0 / Minecraft 1.21.11 / Java 21
Requires a compatible Baritone installation, Fabric Loader and Fabric API. This copy is embedded inside REX. Do not install a separate Overlord jar. Start from the REX Overlord module or .overlord start; stop with .overlord stop. Stopping, death or disconnect releases automation. Starting again plans from actual inventory/equipment.
Implemented: recursive ingredient acquisition; correct player 2x2 versus table 3x3 crafting indices; typed workstation checks; serialized inventory clicks; expected-result checks; full iron/diamond gear prerequisites; ordinary full-frame portal construction and nearby portal reuse; Nether ancient-debris mining; raw ore smelting; loaded-area chest scanning/exploration for a seed netherite upgrade template; template duplication (seven diamonds plus one netherrack and a seed template); smith all six pieces; leather/cane/books/bookshelves/enchanting-table recipes; fifteen-shelf setup; XP collection and level-30 enchanting for each item; completion requires armor, sword and pickaxe all to exist and be enchanted. Cow hunting and eating are included. Final armor equipping is attempted.
Budget: armor+sword+pickaxe = 29 diamond material before upgrades; six upgrades require 24 scraps and 24 gold ingots. A single found template needs five duplication crafts (35 additional diamonds) for six upgrades. Enchanting table and portal materials are additional.
This follows the world that exists: finding a reachable bastion chest, cows, natural obsidian, ores and usable construction sites can fail. Exploration is local/world-dependent and has bounded recovery; this is not a guaranteed run on every seed or server. It does not fabricate items, create enchantments or set server game rules. The first upgrade template must actually be found. Enchantments are the table's real rolls; particular max-level enchantments are not guaranteed. No undetected or ban-free claim.
Validation: modified classes compiled; 338 recipe, resource-budget, crafting-grid and completion-gate checks passed. A Minecraft/Baritone runtime was not available, so the complete zero-to-netherite route and GUI/portal interactions remain untested in game.
Modified source, tests and build-only API stubs are included under overlord-source/. Stubs are not shipped as runtime classes. Extract overlord-source/rebuild.py, then with JDK 21:
python3 rebuild.py overlord-baritone-1.1.0-progression.jar rebuilt.jar
